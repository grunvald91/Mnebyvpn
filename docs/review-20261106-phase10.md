## Установленные ограничения

- At-most-once отправка не означает guaranteed delivery: при UNKNOWN заказ остаётся в неизвестном состоянии, нельзя автоматически отправлять второй invoice. Для восстановления требуются наблюдаемость состояния, обслуживание и новый заказ по явному действию пользователя.
- Во время panel-node partition можно гарантировать ограничение по заранее установленному узловому expiry только после реального подтверждения таких свойств узла. Мгновенный refund revoke при network partition НЕ доказан и не должен обещаться.
- Симуляция новой/существующей сессии НЕ заменяет on-wire проверку существующего TCP/UDP туннеля, Android Private DNS, DNS leak, SNI ingress, узловой памяти и перезапуска.
- Пробный entitlement, который ни разу не активирован, намеренно НЕ удаляется/переоформляется автоматически. Требуется ограниченный operator reset после подтверждения отсутствия stale узлового доступа.
- Внутри Telegram цифровые услуги продаются только через Stars по https://core.telegram.org/bots/payments-stars ; Prodamus готовится отдельно для самостоятельного авторизованного сайта.
- Для полноценного запуска всё ещё необходимы реальная выдача профилей, подключение авторизованных адаптеров, подтверждённые live оплаты, цены, privacy/legal и реальная поддержка платежей (/paysupport). Эти блокировки нельзя снять только прохождением CI.
