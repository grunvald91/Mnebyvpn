## Не закрыто и не должно маскироваться

- **P0-DATAPLANE и P0-OFFLINE**: нет подтверждения работы Xray/Remnawave Node, отключения уже открытых TCP/UDP сессий при expiry, reboot/partition и отсутствия DNS leaks. Панель сама не является сетевым доказательством. Текущий worker **не активирует** новые подписки без независимого механизма hard expiry.
- **P0-DEPLOY**: workflow работает только при `MNEBYVPN_DEPLOY_ENABLED=true`, действительных SSH секретах, выделенных user services и готовой БД. Пропущенный запуск не означает успешный production deployment.
- **P0-PAY**: реальная оплата и юридические проверки остаются отдельно заблокированными.
