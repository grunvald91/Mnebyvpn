# Этап 8 — кнопочное управление, реферальный путь и 1 день бесплатно

## Основной сценарий пользователя
Никакой необходимости вводить `/share`, `/plans` или другие команды вручную:
- Постоянная **reply-клавиатура**: «Выбрать доступ», «Мои подписки», «Поделиться», «Пробный день», «Помощь».
- **Inline-клавиатура**: выбор VPN / Smart DNS / комплекта, срока, покупки Stars, пробного дня, возврата в меню. Сумма и условия берутся из PostgreSQL.
- Экран «Поделиться» отправляет публичный пересылаемый Telegram HTMLBubble (Bot API 10.4) с вкладками услуг, **ценой и сроком каждого реально опубликованного тарифа**. До 16 вариантов, ограниченных 1024 байт `public_data`, без приватных данных.
- Отправитель пересылает Bubble другу; друг выбирает VPN/DNS и срок прямо в нём → Telegram deep link `t.me/<bot>?start=r<token>` → бот создаёт идемпотентный заказ и сразу предлагает **Stars invoice**, без повторного выбора. **В первый раз Telegram может потребовать системную кнопку Start**; подтверждение самого платежа обязательно.
- Кнопка «Попробовать 1 день» в Bubble (только для включённого пробного предложения) ведёт `?start=t<token>` и регистрирует 24-часовой пробный entitlement без фиктивной оплаты.

## Сроки и цены
`db/migrations/0008_pricing_drafts.sql` содержит восемь **неопубликованных заготовок**:
VPN и Smart DNS по **15 / 30 / 60 / 90 дней** (в интерфейсе 60≈2 мес., 90≈3 мес.; это фиксированная длительность, не календарная подписка).
**Числовые цены неизвестны, в SQL оставлены NULL**. DNS-квота также задаётся владельцем. Публикация возможна после заполнения и утверждения тарифов в `billing_plans`.
В реферальном Bubble показываются реальные рубли и Stars из опубликованного каталога, **без автоматического конвертирования**. Выставленный счёт использует immutable `order_terms`, а stale inline-кнопка отвергается по fingerprint даже при конкурентном изменении цены.

## Пробный день
`db/migrations/0007_trials_and_throttle.sql`:
- `trial_offers`: VPN, Smart DNS и комплект, по 86400 секунд; **все выключены до проверки серверной выдачи**, чтобы не обещать доступ, который пока невозможно предоставить.
- `trial_grants`: один пробный период на `telegram_user_id` и `account_id`; транзакция сериализует одновременные клики, защита от самореферала.
- `orders.state=TRIAL`, `provider=internal_trial`, `amount_minor=0`: отдельный учёт бесплатного доступа, **без записи фиктивного события платежа**.
- Создаёт entitlements+outbox, но **не выдаёт сетевой профиль**, пока нет действующего провизионера. Сейчас 24 часа считаются с момента резервирования; до публичного включения нужен тест бизнес-политики «24 часа фактически доступного подключения» и offline expiry.

## Исправления code review
- Старая проблема покупки по индексу уже устранена, теперь fingerprint сравнивается и **внутри PostgreSQL-транзакции** с блокировкой тарифа `FOR SHARE`: внезапное изменение суммы/срока приводит к явному отказу.
- `checkout_requests` сохраняет идемпотентность update/callback. Добавлен account row lock и cap **до трёх PENDING-заказов за 15 минут**. Истёкшие неоплаченные заявки переводятся в CANCELLED.
- `answerCallbackQuery` посылается сразу; pre-checkout получает отрицательный ответ после timeout и не одобряет невалидный платёж; widget_query должен ответить до 15 секунд даже при медленной DB.
- Реферальный Bubble отделён от личного `chat_data`, использует только публичный `public_data`. Цена в пересланном снимке может устареть, окончательная стоимость проверяется в боте.
- Скрипт реферального Bubble не выполняет произвольные сетевые запросы — только доверенный Telegram bridge `openTelegramLink` с проверенным deep-link.
- Продамус и Stars сохраняются. **Stars оплачивается из Telegram, рублёвый checkout Продамус на независимом сайте ещё не подключён к реферальному переходу**. Цена ₽ отображается информационно.

## Что пока не выполнено
Реальное испытание Telegram 10.4 HTMLBubbles, платежей, Prodаmus API, VPN/DNS provisioner, on-wire quotas, expiry при отказе панели. Сетевые серверы не изменялись. Перед слиянием нужен успешный CI на текущем HEAD и проверка расхождения ветки с main.
