# Совместимость клиентов: тестовая матрица

**Не объявлять поддержку, пока не пройдены реальные испытания.** Наличие приложения в App Store зависит от региона/Apple ID и может изменяться. Проверять ссылку и фактическую установку перед публикацией инструкций.

| Клиент | Целевые ОС | Сначала пробуем | Проверено в MNEBYVPN |
|---|---|---|---|
| INCY | iOS/Android, где доступен | Xray JSON / Base64 | НЕТ |
| Happ | iOS/Android и др., где доступен | Xray JSON / Base64 | НЕТ |
| OneXray | iOS | Xray JSON | НЕТ |
| Karing | iOS/Android | sing-box / подходящий поддерживаемый формат | НЕТ |
| Shadowrocket | iOS | Base64 / URI | НЕТ |
| v2rayNG | Android | Base64 / URI | НЕТ |
| v2rayN | Windows | Base64 / Xray JSON | НЕТ |
| NaixGame | iOS | Формат определить по результатам теста | НЕТ |

Это **кандидаты**, а не гарантированный список совместимости. Фактическая доступность iOS-приложений проверяется для RU App Store и других регионов отдельно.

## Contract test для каждого клиента

1. Проверить название, разработчика, оригинальную страницу магазина, ОС и версию.
2. Создать тестового пользователя (не production) и HTTPS URL подписки.
3. Импортировать URL / обновить подписку / переподключиться после смены узла.
4. Проверить сам VPN-транспорт: VLESS/REALITY P0, XHTTP и другие только позднее.
5. Доказать отзыв доступа: **уже импортированная** конфигурация должна перестать проходить аутентификацию.
6. Проверить поведение при истёкшем сроке, временной недоступности URL, потере узла.
7. При HWID: проверить отправляемые заголовки, смену устройства, ошибочное ограничение и восстановление.
8. Записать результат и версию в таблицу: дата, клиент, ОС, формат, транспорт, pass/fail, ссылка на sanitized report.

## Правила подписок

- Использовать **штатные** Remnawave templates и Response Rules (user-agent и другие сигналы нельзя считать надёжной аутентификацией).
- Не распространять действующие URL и QR в публичных логах/тикетах.
- Одно коммерческое право на доступ допускает несколько клиентских приложений **только в пределах тарифной политики**.
- Разные форматы могут отражать один набор узлов; но не все форматы передают одинаковую маршрутизацию/DNS.
- Открытие URL в браузере и импорт в VPN-клиент — разные сценарии.
- Протоколы и форматы не равнозначны: конвертация формата не добавляет клиенту неподдерживаемый transport.
