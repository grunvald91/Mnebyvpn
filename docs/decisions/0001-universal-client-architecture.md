# ADR-0001 — Универсальные VPN-клиенты

Дата: 2026-11-05. Статус: архитектурное решение, НЕ проверено реализацией.

Remnawave/Xray является независимой серверной платформой для VPN. Клиентские подписки через HTTPS обслуживаются встроенными templates / response rules и должны проверяться по версиям приложения и ОС. Нельзя привязываться только к INCY/Happ, особенно когда приложение недоступно в региональном App Store. Не создавать собственный универсальный конвертер подписок до документированной необходимости. При expiry серверная авторизация уже импортированного ключа должна прекратиться.

**Важно:** добавленный позже MNEBYDNS — **не** клиентский формат Remnawave, а отдельный product/data plane с самостоятельной конфигурацией и доступом.

Источники: https://docs.rw/learn-en/templates/ ; https://docs.rw/learn-en/routing-rules/ .
