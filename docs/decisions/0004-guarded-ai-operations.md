# ADR-0004 — ИИ наблюдает, deterministic controller решает

**Дата:** 2026-11-05; **статус:** проектное решение, реализация отсутствует.

## Контекст
Требуются мониторинг, самовосстановление и автоматическое масштабирование VPN + DNS сети при перегрузке. LLM может неверно диагностировать сетевые сбои, а неограниченные cloud API тратят деньги и создают риски.

## Решение
- Объективные probes/metrics + policy engine с cooldown, idempotency и typed allowlisted runbooks.
- ИИ отвечает за анализ, объяснение причин, рекомендации и подготовку изменения к ревью. Не отдавать ИИ root/SSH/provider secrets.
- Безопасные низкорисковые действия разрешены автоматом при подтверждённом событии.
- Масштабирование возможно через API/IaC **после** выбора провайдера, тестов capacity и утверждения hard caps. Бюджет по умолчанию 0; платные специальные узлы — всегда manual approval, пока владелец не изменил политику.
- Созданный узел не подключается пользователям до health check, contract test, canary и audit.
- Автоматическое уничтожение/отключение production VPS не включать по умолчанию.

## Последствия
Сложнее, чем скрипт «если CPU высокий, запусти сервер», но снижает вероятность денежных потерь и масштабирования из-за ложных сигналов. На двух VPS нет полной HA.
