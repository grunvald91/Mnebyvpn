# ADR-0002 — Два VPS сейчас, новые узлы по необходимости

Дата: 2026-11-05. Статус: условно, требуется ресурсо-портовый preflight.

Два VPS уже заняты Telegram-прокси. Один узел кандидат на control plane/Panel+API/DB после свежего приватного capacity audit; второй — на VPN data plane/Xray Node после отдельного теста. Публичная сетевая карта, назначения узлов и занятые порты не публикуются. Node host network не изолирует порты хоста. MNEBYDNS отложен за границу MVP.

**Нет автоматической покупки третьего VPS.** До проверки реальных ресурсов **после уже выполненного владельцем resize** и проверки зашифрованных offsite бэкапов серверы не меняются. Autoscaling через API/IaC включается позднее после согласованных hard caps. Дорогой `special` узел — manual по умолчанию и без обещаний обхода сетевого allowlisting.
