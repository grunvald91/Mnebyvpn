# ADR-0007 — оплачиваемый MVP и граница исследований

Дата: 2026-11-06. Статус: **решение по объёму MVP / не разрешение на запуск**.

## Включаем в MVP

1. VPN на Xray/Remnawave только после P0-NET и реальных испытаний узла; не менять старые прокси без согласия владельца.
2. TypeScript API/Telegram-бот с проверенными entitlements, транзакционными платежами, outbox, revoke/renew, 24-часовым trial после фактической активации (пока отключён).
3. Независимый HTTPS-кабинет с проверенной сессией: войти, увидеть план, дату окончания, оставшиеся дни, лимит и расход трафика **там, где сетевой счётчик реально измеряет байты**, купить/продлить, посмотреть оплату и поддержку. Сначала private/staging без приёма денег.
4. Платежи: внутри Telegram — Stars для цифровой услуги; самостоятельный сайт может использовать отдельно согласованный веб-эквайринг. Live merchant и legal gates до приёма денег. Тарифы 15/30/60/90 дней — черновики без утверждённых цен.
5. Лёгкий мониторинг и алерты; никакой автоматической покупки инфраструктуры и свободных root-команд ИИ.

## Откладываем до обособленных экспериментов

- Системный Android Private DNS / DoT как защищённый DNS-only: можно исследовать resolver, но **не выдавать за транспортный обход, не считать DNS-запросы гигабайтами**.
- Персональный HTTPS/SNI relay на основе DNS rewrite: **не коммерческий режим**. DNS-токен не переносится в TCP/TLS-сессию. Уникальный destination IPv6 — передаваемый bearer-адрес, зависит от IPv6 хостера/клиентов и уязвим к чужому расходованию квоты; нельзя обещать IPv4-only поддержку.
- Опциональный HTTP CONNECT / SOCKS с явной аутентификацией — отдельный будущий продукт, требует настройки на клиенте и самостоятельных тестов. VPN — текущая проверяемая альтернативная реализация платного трафика.
- AI-ops, autoscaling, special nodes и собственный Android Always-on клиент — после безопасного MVP/тестов. Требование совместимости Private DNS + VPN [ADR-0006](decisions/0006-private-dns-vpn-privacy-performance-egress.md) сохранено как цель, **UNVERIFIED**.

**Общая квота MNEBYDNS без HWID** — бизнес-требование, не реализуемая автоматически функция Android Private DNS. Не объявлять её существующей функцией. Сохранить исследование в [ADR-0005](decisions/0005-shared-dns-quota.md).

## Коммерческий стоп

Пока хотя бы один P0 из [единого реестра](release-gates.md) остаётся BLOCKED, не включать live paid checkout, не публиковать платные Smart DNS обещания и не менять действующие VPS. Локальные unit/integration проверки не снимают stop.
