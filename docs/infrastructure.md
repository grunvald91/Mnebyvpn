**План. Не разворачивать до отдельного разрешения.** Имена `ru-edge`, `foreign-exit` — логические; никакие действующие IP/ключи/внутренние интерфейсы в публичный репозиторий не добавляем.

## Целевая расстановка, после проверки

| Компонент | Где | Условие |
|---|---|---|
| Remnawave Panel, DB, Subscription endpoint | ru-edge | Увеличить ресурсы ориентировочно до >=4 GB RAM, >=2 vCPU, >=30 GB диска; подтвердить фактические потребности и конфликты |
| MNEBYVPN API / bot | ru-edge | Отдельные контейнеры, запасы RAM/CPU; метрики и ограничение ресурсов |
| Remnawave Node / Xray | foreign-exit | Сначала параллельный тест без изменения действующего Xray и nginx; подтвердить ресурсы/диск |
| Дублирующие узлы | отдельные VPS **позднее** | Когда появится нагрузка/доход или доказанная потребность |
| Нетбук с 2 GB RAM | инструмент администрирования | SSH, проверка, бэкапы; не production control plane |

Это **целевые ориентиры ресурсов**, а не уже заказанный тариф хостинга. Если resize ru-edge невозможен или дорог, нужно пересмотреть ADR: сначала пилот на существующем Xray и лёгком API **без публичного запуска платной системы**, либо иное размещение по новому решению.

## Предупреждения о текущих прокси

- На foreign-exit публичный :443 занят nginx; Xray прежде работал на внутреннем :8443. **Нельзя** отдавать :443 другому контейнеру, не восстановив полную карту stream/SNI.
- На ru-edge есть критичные сторонние службы и ограничение памяти; текущие web/proxy входы и WireGuard нельзя перезаписывать.
- **Не запускать** произвольный установщик, который автоматически меняет firewall, nginx, Docker networks или существующие порты.
- Не перемещать сервисы до зафиксированных бэкапов, тестового восстановления и rollback.

## Масштабирование

Control plane и data plane изолированы; к Remnawave подключаются новые Node и наборы клиентских профилей. Переезд панели — миграция PostgreSQL + секретов + DNS/сертификатов + API credentials + восстановление/сверка; это **не zero-downtime автоматически**. Долговременный домен подписки должен быть нашим управляемым доменом, конкретное имя пока **не выбрано**.

## Требуемые preflight-измерения непосредственно перед монтажом

`nproc`, `free -h`, `df -hT`, `df -i`, `ss -lntup`, `docker ps`, `systemctl --type=service`, путь Xray и версия, TLS/SNI-routing, WireGuard, UFW/iptables/nftables, возможная компрометация. Только read-only. Затем оценка пиковых метрик, не только idle.
