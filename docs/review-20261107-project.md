# Ревью изменений 6–7 ноября 2026

База: `b2aff5eee85b57fe4da899526a2fc63460004fee` (`main`). Даты — МСК.
Ревью охватывает сайт, email/Telegram identity, Prodamus/Stars, SQL credits/refunds,
выдачу подписок, worker, уведомления, поддержку и связанные инфраструктурные роли.
Также просмотрены отдельные незавершённые ветки #5, #36, #38, #43 и #45.
Это анализ кода и автоматические проверки, не подтверждение реального платежа,
почтовой доставки, прохождения трафика или интерфейса INCY на устройстве.

## Исправления main

1. **P1 — email-вход оставался на экране кода.** `finishEmail` делал переход
   с `/` на `/#account`, который не перезагружает документ. `state.loggedIn`
   оставался false, периодический refresh выключен. Теперь сразу загружается
   `/api/me` и однократно выполняется сохранённая заявка на trial.
   Регрессия: `tests/web-client-referral.test.ts`.
2. **P1 — платное продление пробного доступа не зачислялось.** UI разрешал
   продлить активированный trial, но `settle_verified_payment` требовал
   существующий `entitlement_credits`, которого у trial нет. Новая миграция
   `0102` создаёт проверенную бесплатную базу периода перед первым платным
   продлением. Возврат снимает только оплаченный период; непросроченный trial
   сохраняется. Исторические миграции не изменены.
   Регрессия: `tests/integration/website-renewal.test.ts`.
3. **P1 — возврат Stars зависел от необязательного `message.from`.** Основной
   cabinet отклонял service message до проверки refund. Теперь возврат привязан
   к private chat, исходному заказу, сумме, валюте и charge ID через подписанный
   webhook; успешная покупка по-прежнему требует корректного отправителя.
   Регрессия: `tests/integration/telegram-cabinet-stars-live.test.ts`.
4. **P1 — ссылка одной покупки ломалась при наличии другой.** Worker выбирал
   максимальный срок всего аккаунта, затем сравнивал с ID исходной ссылки.
   Теперь lookup фильтрует конкретный entitlement вместе с владельцем.
   Кнопка сайта также передаёт ID своей карточки вместо выбора чужого периода
   того же аккаунта. Регрессия: `tests/integration/vpn-profile-ownership.test.ts`.
5. **P1 — сайт пытался создать bearer через SELECT-only роль.**
   `VPN_SUBSCRIPTION_DATABASE_URL` имеет роль `mnebyvpn_sub_ro`; INSERT из
   `/api/vpn/subscription` получал permission denied. Выпуск ссылки теперь
   использует canonical auth pool с точечным INSERT в `vpn_subscription_links`.
   `0103` обновляет уже существующие роли; infra setup получает те же GRANT
   для новых установок. Reader остаётся read-only; auth не может менять
   entitlement или создавать заказ. Регрессия:
   `tests/integration/website-subscription-role.test.ts`.
6. **P2 — напоминания за пределами первой страницы не создавались.** LIMIT
   применялся до исключения уже известных deadlines; ON CONFLICT повторно
   отбрасывал первые 200. Теперь очередь исключает их перед LIMIT.
   Регрессия: `tests/integration/telegram-expiry-reminders.test.ts`.

## Незавершённые ветки и ограничения

- #38: email/auth реализация уже перенесена в main; оставшаяся старая ветка
  конфликтует и не должна заменять новые изменения main.
- #5: старые альтернативные миграции `0012–0014` конфликтуют по смыслу с текущей
  историей БД. Нельзя применять её как готовое обновление; новые идеи нужно
  переносить отдельно. Текущий main уже содержит часть прежних исправлений.
- #36: metadata/renewal для INCY остаётся отдельной веткой; поведение клиента
  с истёкшей подпиской требует устройства. В этом ревью функциональность
  из ветки не объявляется выпущенной.
- #43/#45: дополнительный node registry/fanout не подключён к production worker;
  его green CI не доказывает работу нескольких реальных серверов.
- В инфраструктурном node agent обнаружен лимит срока в 100 дней: продление
  на 90 дней при остатке 30 дней давало 120 дней и отклонялось. Исправление
  и изолированные тесты агента идут в инфраструктурном PR.
- Системная установка PostgreSQL в локальном runtime недоступна (setgroups/
  seteuid permission errors). Полная SQL/integration проверка выполняется
  штатным CI с disposable PostgreSQL; её результат фиксируется в PR.
- Деплой и реальный платёж данным ревью не подтверждены. Новые миграции и
  изменения ролей должны пройти обычный проверяемый release path.
