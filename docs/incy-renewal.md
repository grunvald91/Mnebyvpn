# INCY: продление из приложения без Telegram (06.11.2026)

Документация: https://docs.incy.cc/app-management/ и
https://docs.incy.cc/subscription-format/

## Реализованные серверные контракты

- По прежнему HTTPS `/sub/<opaque-token>` выдаются `profile-title: MNEBYVPN`,
  `profile-web-page-url: https://mnebyvpn.site/`,
  `support-url: https://t.me/MnebyVPN_bot` и
  `premium-url: https://mnebyvpn.site/#account`.
  Все эти ссылки публичные и не содержат пользовательский token.
- `subscription-userinfo` сохраняет `expire`; `profile-update-interval: 1`.
  Поля трафика пока **не являются фактическими измерениями**.
- При оставшихся <=72 часах либо после окончания сервер добавляет
  `announce` и `announce-url` (ссылка на независимый сайт).
- `expiry-banner-*` настраивает текст/кнопку в INCY, **но отображение зависит от
  активной Premium-подписки провайдера в INCY**. На обычном клиенте остаются
  ссылка на сайт, поддержка, и объявление.
- Обычное истечение срока (e.state=EXPIRED или ACTIVE с истекшим expires_at)
  не уничтожает ссылку: `GET /sub/<token>` возвращает 200 с
  метаданными и **без VLESS-ключа**. Отозванные, отменённые, оплаченные
  возвратом и неизвестные токены остаются 404.
- После подтверждённого продления того же entitlement и node ACK старый
  URL вновь отдаёт его VLESS-конфигурацию. Сам HTTP-ответ никогда не
  предоставляет доступ к VPN при истечении; применимость ключа определяет
  узел Xray.

## Границы готовности (важно)

- **Вход без Telegram**: разрабатывается в отдельном
  [PR #31](https://github.com/grunvald91/Mnebyvpn/pull/31). В main сейчас
  веб-кабинет использует только Telegram OIDC. Пока PR не выпущен и не
  проверена доставка OTP через ServGo, «продлить без Telegram» *не E2E-ready*.
- Кнопка сайта не спасает при недоступном DNS/TLS/HTTPS сайта из обычной
  сети. Перед релизом проверить `https://mnebyvpn.site/` без VPN, с мобильной
  сети и Wi-Fi. Дополнительные домены только после независимой проверки.
- INCY на Android v3.9.7 требуется протестировать с **конфигурацией без
  серверов после expiry**: в официальной документации есть правила
  метаданных, но отсутствует гарантия UI при таком ответе. Не обещать
  показ баннера или автоматическое восстановление без device E2E.
- Нужен реальный сценарий: импорт активного URL → до 72ч → истёк →
  обновить подписку → перейти на сайт без Telegram → войти по email →
  оплатить через Prodamus → подтверждённый подписанный webhook →
  node ACK → обновить тот же URL и подключиться. До прохождения всего
  сценария статус только **CODED / TESTED_OFFLINE**.
- Не включать платежи/новые VPN-узлы без требований
  [release-gates.md](./release-gates.md). Профильные метаданные не
  подтверждают работающую оплату.
