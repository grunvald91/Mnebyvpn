# Мне бы VPN · MNEBYVPN

**Статус:** архитектура утверждена как проектное направление; реализация и установка на серверы ещё не начаты.

Проект универсального сервиса VPN-подписок. Пользователь покупает доступ один раз и подключается через **совместимый сторонний клиент** (INCY, Happ, OneXray, Karing, v2rayNG и др. после проверки). Собственное VPN-приложение на первом этапе не разрабатываем.

## Решение

- **Data plane:** Xray-core в составе Remnawave Node; начальный профиль-кандидат — VLESS + REALITY. Дополнительные транспорты — только после совместимых сквозных испытаний.
- **Control plane:** Remnawave Panel + API, PostgreSQL; публичные подписки через функциональность Remnawave (шаблоны / response rules).
- **Commercial plane:** собственный TypeScript backend, Telegram-бот на grammY, платёжный адаптер и простой мобильный веб-кабинет. Права доступа и оплаты учитываются в коммерческом backend, доступ применяется на VPN-узлах.
- **Инфраструктура:** два имеющихся VPS, без покупки третьего на первом этапе. Российский — кандидат на панель **только после расширения ресурсов и проверки безопасности**; зарубежный — кандидат на VPN Node после аккуратной миграции.
- **Специальные узлы:** будущий необязательный тип узла для операторских ограничений/белых списков. Никакой гарантии работы на таких сетях до измерений нет.
- **Безопасность:** текущие Telegram-прокси сохраняются, пока не подтверждены бэкапы, изолированная установка, работоспособность и откат.

## Что в репозитории сейчас

Здесь **только документация и правила работы**. Нет конфигураций боевых VPS, рабочих секретов, платёжного backend, контейнеров или автоматического деплоя. Папки `apps/`, `packages/`, `infra/` появятся при реализации. **Ничего не развёрнуто.**
