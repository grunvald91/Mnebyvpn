Системный DNS Windows

Используется персональное имя DoT-сервера из настроек ниже. Клиент меняет DNS непосредственно на сетевых адаптерах Windows: IPv4 и IPv6, включая новые физические подключения Wi-Fi/Ethernet. Туннельные и неизвестные виртуальные адаптеры намеренно не изменяются. Для управления потребуется подтверждение UAC.

Аварийное восстановление допускается только при остановленной службе. Резервные записи удаляются по отдельности и только после точной проверки DNS.

Обновление старой службы доступно только после отключения DNS и подтверждённого восстановления исходных настроек. Для обновления Windows один раз запросит UAC.

Состояние службы ещё не проверялось.

При выключении восстанавливаются исходные режимы и адреса DNS каждого адаптера. Пока восстановление не подтверждено, журнал резервных настроек сохраняется.

Приложения с собственным DoH/DoT и отдельные VPN-политики могут использовать независимый DNS. Их состояние показывается диагностикой.

Проверка DoT-сервера без изменения настроек Windows.

Только имя сервера, без https:// и порта. При включении адрес сохраняется в защищённой конфигурации Windows; в интерфейсе ключ не сохраняется.

При смене сервера потребуется разовое подтверждение администратора. Обычное включение и выключение сохранённого профиля выполняется без UAC.
