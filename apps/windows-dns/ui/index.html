Системный DNS · пробный режим

На 15 минут направляет обычные DNS-запросы Windows через персональный DoT. Использует NRPT, не перезаписывая исходные DNS адаптеров. Нужны права администратора. При существующих правилах VPN включение блокируется.

В отдельном окне администратора потребуется ещё раз ввести персональный DoT-хост. Автооткат запланирован при перезагрузке, остановке прокси или по истечении времени.

Состояние ещё не проверялось. Убедитесь, что в системе нет конфликтующих политик DNS.

Важно: браузер с собственным DoH и отдельные VPN могут обходить системный DNS. Долговременный режим пока не включён.
