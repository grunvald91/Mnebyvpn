# мнебыDNS — Windows 10, тестовая версия 0.9

Это портативная диагностическая версия. Она НЕ меняет DNS Windows и не включает Smart DNS для всех программ.

## Запуск

1. Откройте [сборки Windows](https://github.com/grunvald91/Mnebyvpn/actions/workflows/windows-dns-rust.yml?query=branch%3Afeature%2Fwindows-dns-rust-tray), выберите последний успешный запуск.
2. В разделе **Artifacts** скачайте архив **mnebydns-win10-diagnostics-unsigned**. Для загрузки GitHub может потребовать вход в аккаунт.
3. Распакуйте архив. Запустите **mnebydns-windows.exe** двойным нажатием, без запуска от имени администратора.
4. В поле **«Адрес персонального DNS»** укажите только имя личного DoT-сервера из вашей подписки, без https:// и порта. Не используйте адрес DoH (с /dns-query).
5. Нажмите **«Проверить подключение»**. Программа сначала проверит сертификат TLS и DNS-запросы A/AAAA, затем временный локальный UDP-прокси через тот же DoT.
6. Попробуйте свернуть окно в трей, вернуть его нажатием на иконку, открыть «Диагностику» и «Настройки».

## Результаты

**«Проверки пройдены»** — DoT и временный локальный UDP-прокси отвечают. Это пока НЕ означает, что Windows использует наш DNS для всего трафика, что внешний IP сменился или что YouTube разблокирован.

**«DoT не прошёл проверку»** — проверьте персональное DNS-имя и доступность TCP 853. Смотрите точную ошибку на первом этапе.

**«Прокси не прошёл проверку»** — TLS/DoT удалось проверить, но локальный UDP-тест завершился ошибкой.

В «Диагностике» показан также обычный локальный DNS, который может работать независимо от нашего DoT.

## Важно для первой проверки

- EXE не подписан цифровой подписью; SmartScreen может показать предупреждение. Проверяйте источник и SHA-256 из файла SHA256.txt. Не отключайте защиту Windows ради запуска.
- Нужен Microsoft Edge WebView2 Runtime. Если окно не появляется, проверьте его установку на официальной странице: https://developer.microsoft.com/microsoft-edge/webview2/
- Отдельную Windows-службу (архив mnebydns-win10-service-setup-unsigned) для просмотра дизайна и двух сетевых тестов устанавливать НЕ нужно.
- Персональный адрес не сохраняется. Не публикуйте его на скриншотах или в сообщениях об ошибке.
- Проверьте работу при масштабе Windows 100%, 125% и 150%, с Wi-Fi, Ethernet и при включённом привычном VPN.
