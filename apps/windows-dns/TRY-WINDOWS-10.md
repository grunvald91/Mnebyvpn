# мнебыDNS 0.10 для Windows 10 — пробный системный DNS

Это **тестовая неподписанная сборка**, а не окончательный установщик. На 15 минут она может направлять обычные DNS-запросы Windows через ваш персональный DoT с помощью правила NRPT для всех доменных имён. Исходные DNS-настройки сетевых адаптеров при этом не перезаписываются.

## Безопасная диагностика

1. Распакуйте все файлы архива в одну папку. Откройте mnebydns-windows.exe без прав администратора.
2. Введите личное имя DNS-over-TLS (не DoH-ссылку) и нажмите «Проверить подключение».
3. Проверьте состояние DoT, UDP-прокси, вкладки и трей. Пока это не изменяет системный DNS.

## Пробное системное включение (15 минут)

1. Первый запуск системы DNS лучше проводить на тестовой Windows 10 с доступной альтернативной сетью. Не используйте этот эксперимент в корпоративной сети.
2. Откройте в приложении «Настройки» → «Включить DNS Windows на 15 минут». Подтвердите UAC.
3. В открывшемся окне PowerShell повторно введите персональное имя DoT. В командной строке и файлах оно не сохраняется.
4. Программа запускает локальный сервер UDP/TCP 53 для 127.0.0.1 и ::1, проверяет DNS-ответы и только после этого добавляет системное правило Windows NRPT с namespace «.».
5. Вернитесь в приложение, нажмите «Проверить состояние Windows». Если отображается ACTIVE, правило создано. Проверьте открытие сайтов. Приложения со своим DoH и некоторые VPN могут использовать другой DNS.
6. Для раннего отключения нажмите «Выключить системный DNS» и подтвердите UAC. Также создаётся независимое задание Windows для очистки собственного правила после 15 минут, при перезагрузке или остановке прокси.

## Аварийное отключение

Если приложение не отвечает, откройте PowerShell **от имени администратора**, перейдите в папку с архивом и выполните:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\SYSTEM-DNS.ps1" -Action Disable

Для просмотра состояния без администратора:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\SYSTEM-DNS.ps1" -Action Status

## Важно

- До первого испытания на вашей Windows 10 22H2 нельзя подтвердить фактическую совместимость с сетью, VPN, защитой Windows и планировщиком заданий.
- Если DNS/порт 53 занят или действуют другие NRPT-правила, пробный режим откажется включаться. Это сделано намеренно.
- Системный NRPT затрагивает стандартный DNS-клиент Windows, **но не перехватывает все сетевые соединения**. Частный DNS/DoH приложения, прямые IP-соединения, локальные hosts и DNS внутри VPN могут обойти его.
- DNS не заменяет VPN и не обязательно изменяет видимый публичный IP. Для YouTube и других сервисов нужны отдельные сетевые тесты.
- На время сбоя DoT могут быть ошибки разрешения имён. Поэтому пробный режим автоматически заканчивается. Постоянный режим требует контролируемой Windows-службы, автоматического рестарта и сквозного контроля DNS.
- Не отключайте SmartScreen или антивирус ради запуска неподписанного EXE. Для интерфейса нужен Microsoft Edge WebView2 Runtime.
- Контрольные суммы отдельных файлов находятся в SHA256.txt.
- Не публикуйте личный DNS-хост на скриншотах.
